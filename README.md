# Pixelator (픽셀 정렬 시뮬레이터)

소스 이미지의 픽셀들만을 직접 교환(Swap / Permutation)하여 목표 이미지를 흉내내는 픽셀 정렬 시뮬레이터입니다.
단순히 이미지를 덧칠하거나 보간하는 것이 아니라, **픽셀들의 1:1 보존 법칙(Permutation Only)** 아래에서 고전 정렬 알고리즘이 동작하며 이미지가 재구성되는 과정을 시각화합니다.

## ✨ 주요 특징

1. **2단계 파이프라인 구조**:
   - **1단계 (중간 이미지 최적화)**: RTX 3080 Ti CUDA GPU 가속을 통해 소스 픽셀의 최적 배치 맵(`destination_map`)을 0.2~0.4초 만에 생성 (사용자에게는 숨김).
   - **2단계 (정렬 알고리즘 시각화)**: 2D 공간 분할 퀵소트(Spatial QuickSort), 2D 머지소트(Spatial MergeSort) 등 다양한 정렬 알고리즘을 통해 원본이 점진적으로 변해가는 과정을 단일 캔버스에서 시각화.

2. **최적화 엔진**:
   - **5D 시공간 최적 수송 (Sliced Wasserstein)**: 공간 윤곽과 색상의 조화를 점진적으로 어닐링.
   - **3D RGB 벡터 공간 매칭 (신규)**: 순수 3차원 색공간 상의 다각도 회전 앙상블 투영 + 상호 배타적 2-Opt 병렬 스왑으로 **극소값 자동 완전 수렴**.

3. **초고성능 제로 가비지 (Zero-Allocation) 최적화**:
   - 150만 픽셀(1493x1054) 환경에서도 메모리 누수 없이 **초당 24만 스왑 / 75 FPS 정속 적응형 제어**.
   - Typed 원형 큐와 인라인 좌표 포인터 적용으로 GC 멈춤 현상 제로.

4. **원클릭 실행**:
   - `run.bat` 실행 시 CUDA 가속 환경을 자동 감지하여 서버 및 브라우저를 즉시 실행.
   - 프로젝트 기본 사진(햄스터 V)이 기본 탑재되어 있어 별도 설정 없이 바로 체험 가능.

## 🚀 빠른 시작

```bat
# run.bat 더블클릭 또는 터미널 실행
run.bat
```

서버가 실행되면 자동으로 웹 브라우저(`http://127.0.0.1:5000`)가 열립니다.
